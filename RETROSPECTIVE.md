# Project Retrospective

## What I Learned

During this project, I learned how to build and deploy a Retrieval-Augmented Generation (RAG) application using React, Vite, and the Anthropic API. I gained experience with:

- Building a React frontend using reusable components.
- Implementing a simple RAG pipeline with document chunking, TF-IDF indexing, and cosine similarity retrieval.
- Connecting a frontend to a serverless backend deployed on Vercel.
- Managing Git and GitHub workflows, including commits, rebasing, resolving merge conflicts, and deployments.
- Debugging build errors, JSX syntax issues, and deployment failures.

---

## Where AI Helped

AI was useful for:

- Explaining RAG concepts and application architecture.
- Suggesting code improvements and optimizations.
- Helping debug React, Git, and Vercel deployment issues.
- Generating documentation such as the README and cost audit.
- Explaining errors and providing guidance during development.

---

## Where AI Was Less Helpful

Some AI-generated suggestions required careful review because:

- JSX formatting issues sometimes introduced syntax errors.
- Deployment problems still required checking build logs and understanding the error messages.
- AI suggestions needed to be tested before applying them to ensure they worked correctly.

This reinforced the importance of verifying AI-generated code rather than assuming it is always correct.

---

## Next Goals

In the future, I plan to improve this project by:

- Supporting PDF and Word document uploads.
- Using semantic embeddings instead of TF-IDF retrieval.
- Adding user authentication.
- Maintaining chat history.
- Improving the user interface and user experience.
- Adding automated tests for better reliability.
- Monitoring API usage and costs in production.

---

## Conclusion

This project strengthened my skills in React, Retrieval-Augmented Generation (RAG), API integration, deployment with Vercel, Git workflows, debugging, and project documentation. It also showed me the value of combining AI assistance with careful testing and validation to build reliable software.
